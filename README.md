# Mateen & Associates Website

Production-ready React + Tailwind CSS marketing website for a Lahore-based legal services firm.

## Tech Stack
- React + Vite
- Tailwind CSS
- Framer Motion

## Scripts
- `npm run dev` – Start development server
- `npm run build` – Build production bundle
- `npm run preview` – Preview production build locally
- `npm run lint` – Run ESLint
